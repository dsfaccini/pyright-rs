# Step 5 shares

The split of the evaluator block (`PLAN.md` step 5) for 8 body agents, about 8.2k TypeScript lines each.
Every function, method and type of these files already exists in `crates/pyright/src/analyzer/` with a `todo!()` body, generated by `tools/stubgen` (run `evaluator`).

## find your work

Each Rust item sits under the marker `// analyzer/<file>.ts:<line>` of its TypeScript declaration.
A share owns every marker of its files within its line range, in whatever Rust file the marker sits:

```sh
grep -rn '// analyzer/typeGuards.ts:' crates/pyright/src
```

Fill the `todo!()` bodies under your markers and leave every other marker alone. Git merges disjoint ranges of one file.

## running the code

- `PYRIGHT_RS_CHECKER=1` runs the checker and the types dump stage. Unset, `pyright-rs` parses and binds only and reaches no stub, so the milestone 1 corpus check stays green.
- Allocate with `P::new_eval` (`docs/porting.md`, "memory").
- A rerun of `tools/stubgen/stubgen --run evaluator --install` keeps every ported function at its marker and refuses to run when it would drop other ported code.
